# Nossa Senhora do Ó

Site educativo sobre a história de Nossa Senhora do Ó, em Ipojuca-PE. São 12 capítulos animados que atravessam quatro séculos, de antes de 1608 até hoje. Cada fato traz um selo de fonte: DOC, ACAD, ORAL ou LENDA.

Feito com GSAP, ScrollTrigger e Lenis, num único `index.html`, sem etapa de build. Para ver localmente:

```bash
python -m http.server 5173
```

As decisões de design, e de onde cada uma veio, estão em [DESIGN.md](DESIGN.md).

Pesquisa: Memórias do Ó. Dedicado a Seu Álvaro, guardião da memória oral do Ó.
