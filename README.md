# Nossa Senhora do Ó

Site educativo sobre a história de Nossa Senhora do Ó, em Ipojuca-PE. Uma maquete 3D atravessa quatro séculos em 12 capítulos, e cada fato traz um selo de fonte (DOC, ACAD, ORAL, LENDA).

Feito com three.js, GSAP e Lenis, num único `index.html`. Para ver localmente:

```bash
python -m http.server 5173
```

Pesquisa: Memórias do Ó. Dedicado a Seu Álvaro, guardião da memória oral do Ó.
